# Caderno de Ideias — site HTML estático

Website em HTML e CSS puro, sem Node.js, Astro ou dependências externas. Pronto para publicar no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório (`index.html`, `styles.css` e as quatro páginas HTML).
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)` e salve.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## Editar o conteúdo
Abra cada arquivo `.html` em um editor de texto e substitua os títulos, resumos e textos de exemplo. O menu usa páginas HTML separadas, por isso mantenha os nomes dos arquivos ou atualize os links em todas as páginas.
